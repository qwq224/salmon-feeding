# 三文鱼养殖水质问题诊断与处理

## 一、水质问题快速诊断表

| 观察现象 | 可能原因 | 优先检测项目 |
|---------|---------|------------|
| 鱼浮头/集群水面 | 低氧 | DO |
| 鱼厌食/拒食 | 氨氮/亚硝酸/应激 | NH₃, NO₂⁻, DO, T |
| 鱼擦底/擦壁 | 寄生虫 | 镜检 |
| 鱼体色发暗 | 慢性氨氮中毒/低氧 | NH₃, DO |
| 鱼鳃盖开合过快 | 鳃部问题/低氧/高CO₂ | DO, CO₂, NH₃ |
| 水面大量泡沫 | 有机物超标 | TSS, BOD |
| 水色发黄/浑浊 | 悬浮物多/藻类 | TSS, 藻类镜检 |
| pH持续下降 | 硝化产酸/碱度不足 | 碱度, pH |
| 鱼死亡无明显症状 | 氨氮/亚硝酸/急性缺氧 | NH₃, NO₂⁻, DO |

## 二、溶解氧（DO）问题

### 2.1 DO偏低原因排查

1. 增氧设备故障或功率不足
2. 养殖密度过高，耗氧>供氧
3. 水温升高（DO饱和度下降）
4. 生物滤池耗氧量大（氨氮负荷高）
5. 残饵/有机物分解耗氧
6. 大气压低（雷雨前）

### 2.2 DO日常变化规律

- 凌晨4-6点最低（夜间鱼类呼吸+无光合作用）
- 午后14-16点最高（水温高但光合作用强）
- RAS系统理想DO日变化幅度<2mg/L
- 报警值设定：<7mg/L黄色预警，<5mg/L红色报警

### 2.3 DO管理策略

| 条件 | 增氧策略 |
|------|---------|
| 正常（T<18℃） | 标准曝气，DO目标≥9mg/L |
| 高温（T>20℃） | 增氧量+20-30%，纯氧补充 |
| 高密度（>50kg/m³） | 纯氧为主，DO>10mg/L |
| 投喂后1-2小时 | 增氧量+10%（消化耗氧高峰期） |
| 夜间 | 增氧量+10-15% |

## 三、氨氮（NH₃）问题

### 3.1 氨氮来源分析

| 来源 | 占比 | 控制方法 |
|------|------|---------|
| 鱼类代谢排泄 | 60-70% | 控制投喂量，提高饲料消化率 |
| 残饵分解 | 20-25% | 精准投喂，减少残饵 |
| 粪便矿化 | 10-15% | 及时去除固体废物 |

每公斤饲料（40%蛋白）约产生30g NH₃-N

### 3.2 NH₃与NH₄⁺的转化

总氨氮 TAN = NH₃（有毒）+ NH₄⁺（低毒）

NH₃占比受pH和水温影响：
- pH 7.0, 15℃ → NH₃约占0.3%TAN
- pH 8.0, 15℃ → NH₃约占3%TAN（毒性增加10倍！）
- pH 8.5, 25℃ → NH₃约占15%TAN（极危险！）

关键：**高pH+高温=氨氮毒性急剧放大**

### 3.3 氨氮超标处理流程

1. **立即停食**（减少新氨氮产生）
2. **检测确认**：测TAN+计算NH₃占比（需pH和水温数据）
3. **加大换水**：水源氨氮需<0.1mg/L
4. **调整pH**：如pH>8.0，暂不补碱，等硝化消耗碱度自然降pH
5. **增加曝气**：提高DO至>9mg/L
6. **临时吸附**：沸石粉1-2kg/m³（4-6小时后需更换）
7. **检查滤池**：生物滤池是否正常硝化
8. **持续监测**：每4-6小时测一次

## 四、亚硝酸盐（NO₂⁻）问题

### 4.1 亚硝酸盐中毒机理

NO₂⁻进入血液将血红蛋白氧化为高铁血红蛋白，失去携氧能力，导致"褐血病"。鱼鳃呈褐色，即使DO充足也会缺氧。

### 4.2 亚硝酸盐超标处理

| 浓度 | 措施 |
|------|------|
| 0.1-0.5 mg/L | 增加换水20%/天 |
| 0.5-1.0 mg/L | 换水40%+添加食盐(Cl⁻)0.3-0.5‰ |
| >1.0 mg/L | 大换水+食盐1‰+停食+检查硝化系统 |

食盐（NaCl）的Cl⁻与NO₂⁻竞争鳃部吸收位点，有效降低NO₂⁻毒性。Cl⁻:NO₂⁻-N至少保持10:1以上。

## 五、pH与碱度问题

### 5.1 pH异常原因

| 问题 | 原因 | 处理 |
|------|------|------|
| pH持续下降 | 硝化产酸耗尽碱度 | 补充NaHCO₃ |
| pH突然下降 | 水源pH低/酸雨 | 加大补碱量 |
| pH偏高 | 补水pH高/过量加碱 | 减少补碱/增换水 |
| pH昼夜波动>0.5 | 碱度不足（缓冲能力弱） | 提高碱度至>100mg/L |

### 5.2 碱度补充计算

碱度目标：50-200mg/L CaCO₃

NaHCO₃用量 (g/m³) = 目标碱度 - 当前碱度 (mg/L CaCO₃) × 1.68

例如：当前碱度30，目标100，100m³水体
需NaHCO₃ = (100-30) × 1.68 × 100 = 11,760g ≈ 11.8kg

**注意**：分2-3次加入，间隔2小时以上，避免pH剧烈波动。

### 5.3 碱度消耗估算

RAS系统中：
- 每kg饲料（40%蛋白）约消耗250-350g CaCO₃碱度
- 日投喂100kg饲料 → 日消耗约30kg CaCO₃碱度
- 需日补NaHCO₃约50kg（100m³系统）

## 六、CO₂问题

### 6.1 CO₂来源与危害

来源：鱼类呼吸+硝化菌呼吸
危害：>15mg/L → 血液pCO₂升高 → 血液pH降低（呼吸性酸中毒）→ O₂亲和力下降

### 6.2 CO₂控制

| 措施 | 效果 |
|------|------|
| 脱气塔（标准配置） | 去除率60-80% |
| 增加曝气 | 辅助去除 |
| 控制碱度 | 缓冲血液pH |
| 降低密度 | 减少CO₂产生 |
| 增补水 | 稀释CO₂浓度 |

脱气塔气水比建议5:1-10:1，填料需定期酸洗去除结垢。

## 七、总悬浮物（TSS）

### 7.1 TSS超标的影响

- 堵塞鳃丝 → 呼吸障碍
- 为异养菌提供基质 → 与硝化菌竞争
- 降低UV消毒效率
- 增加BOD → DO消耗↑

RAS系统TSS目标：≤15mg/L

### 7.2 TSS去除设备

| 设备 | 去除粒径 | 效率 |
|------|---------|------|
| 弧形筛 | >1000μm | 粗滤 |
| 滚筒微筛机 | 60-200μm | 主要固液分离 |
| 蛋白分离器 | 溶解有机物 | 泡沫分选 |
| 砂滤罐 | 20-50μm | 精滤 |
| 沉淀池 | — | 重力沉降 |
