# 三文鱼养殖应急处理完全手册

## 一、缺氧应急

### 1.1 分级响应

| 级别 | DO范围 | 症状 | 应急措施 |
|------|--------|------|---------|
| 轻度 | 5-7 mg/L | 摄食减少 | 增氧量+30%，减少投喂20% |
| 中度 | 3-5 mg/L | 浮头、集群水面 | 全负荷增氧+纯氧补充，停食，准备换水 |
| 重度 | <3 mg/L | 大口呼吸、失衡 | 立即停食，纯氧全开，紧急换水50% |
| 危急 | <2 mg/L | 大批死亡 | 所有增氧手段全开，大换水80%+ |

### 1.2 纯氧紧急供氧操作

1. 打开液氧罐主阀→调节减压阀至0.2-0.3MPa
2. 启动溶氧锥/LHO（低压增氧装置）
3. 监测养殖池DO，目标恢复至≥7mg/L
4. DO恢复到5mg/L以上后，逐步恢复正常增氧
5. 纯氧使用时严禁明火

### 1.3 缺氧原因排查

- 停电→启动发电机/UPS
- 曝气设备故障→切换备用设备
- 生物滤池堵塞→反冲洗
- 密度过高→临时分池或降低密度
- 高温（>22℃）→降温+减少投喂

## 二、氨氮超标应急

### 2.1 超标分级与措施

| 级别 | NH₃-N (mg/L) | 措施 |
|------|-------------|------|
| 轻度 | 0.2-0.4 | 减少投喂15%，增加换水20%/天，补充硝化菌 |
| 中度 | 0.4-0.6 | 停食1天，换水40%/天，添加沸石粉1kg/m³ |
| 重度 | 0.6-1.0 | 停食2-3天，换水50%/天，检查生物滤池 |
| 危急 | >1.0 | 立即停食，大换水80%+，排查死鱼，考虑紧急出鱼 |

### 2.2 具体操作步骤

1. **立即停食**（减少氨氮来源）
2. **加大换水**：先用检测确认水源氨氮<0.1mg/L
3. **补充碱度**：添加NaHCO₃维持碱度>50mg/L（硝化菌需要）
4. **增加曝气**：提高DO至>9mg/L（硝化耗氧）
5. **添加沸石粉**：1-2kg/m³，吸附氨氮（临时措施）
6. **检查生物滤池**：pH是否正常、填料是否堵塞、有无死区
7. **添加硝化菌种**：市售硝化菌制剂，按说明使用
8. **持续监测**：每4小时测一次NH₃-N

### 2.3 亚硝酸盐超标

NO₂-N>0.5mg/L时的处理：
- 添加食盐（NaCl）：浓度0.3-0.5‰（3-5kg/10m³），Cl⁻竞争性抑制NO₂⁻吸收
- 其余措施同氨氮超标

## 三、高温应急

### 3.1 高温分级

| 级别 | 水温 | 措施 |
|------|------|------|
| 注意 | 20-22℃ | 减少投喂15%，加强增氧 |
| 警告 | 22-24℃ | 减少投喂30%，24h增氧全开 |
| 危险 | 24-26℃ | 停食，降温措施全开 |
| 危急 | >26℃ | 停食，紧急降温，考虑提前出鱼 |

### 3.2 降温措施

1. **加大补水**：使用低温水源（地下水/深层水）
2. **遮阳**：养殖池上方加盖遮阳网（减少辐射热）
3. **蒸发降温**：增加水面扰动和曝气
4. **热泵制冷**：有条件的开启制冷系统
5. **减少代谢产热**：停食减少消化产热
6. **纯氧增氧**：高温下DO饱和度降低，需纯氧补充

### 3.3 高温期管理要点

- DO目标从9mg/L提高至>10mg/L
- 投喂时间改至清晨5:00-6:00（一天中最凉时段）
- 减少投喂频率（1-2次/天）
- 密切观察鱼群行为（高温应激：浮头、离群、体色发暗）
- 备好冰块或液氮应急降温

## 四、停电应急

### 4.1 停电响应流程

| 时间 | 行动 |
|------|------|
| 0分钟 | 发电机自动启动（ATS切换<30秒） |
| 1分钟 | 确认发电机运行、电压正常 |
| 2分钟 | 确认水泵、增氧设备恢复运行 |
| 5分钟 | 检查所有养殖池DO |
| 10分钟 | 通知电力部门，确认停电原因和预计恢复时间 |
| 持续 | 每15分钟巡检一次DO和鱼群状态 |

### 4.2 无发电机或发电机故障

- 立即启动UPS（维持关键设备30-60分钟）
- 手动纯氧供氧（液氧罐→减压阀→曝气石放入各池）
- 人工搅动水面增加溶氧
- 联系电力抢修/租用移动发电机
- 各池均匀分配氧气

## 五、病害爆发应急

### 5.1 发现异常死亡

1. **立即隔离**：病鱼/死鱼捞出，单独处理
2. **记录**：死亡数量、症状、发病时间
3. **停食**：发病初期停食24-48小时
4. **采样送检**：取3-5尾濒死鱼送实验室
5. **消毒工具**：所有接触病鱼的网具、水桶严格消毒
6. **加强增氧**：病鱼耗氧增加

### 5.2 常见病急处理

| 病症 | 初步判断 | 应急处理 |
|------|---------|---------|
| 体表出血+鳍基发红 | 弧菌病 | 氟苯尼考10mg/kg/天×7天 |
| 鳃丝苍白+贫血 | ISA/贫血症 | 立即报告+全群检测 |
| 鱼体发黑+螺旋游动 | IPN | 提高水温至16-18℃ |
| 鳃丝白点+粘液多 | 小瓜虫/车轮虫 | 福尔马林浴25-50ppm |
| 体表溃疡+棉絮状 | 水霉病 | 提高水温+食盐水浴 |

## 六、设备故障应急

### 6.1 水泵故障

- 立即切换至备用水泵
- 如无备用泵，暂停投喂，减少系统负荷
- 人工搅动水面维持DO
- 尽快修复或更换

### 6.2 生物滤池故障

- 滤池崩溃（NH₃快速上升）：大换水+添加沸石粉+补充硝化菌
- 滤池堵塞（水位差大）：反冲洗或降低循环流量
- pH骤降（<6.5）：立即补充NaHCO₃

### 6.3 供氧系统故障

- 液氧罐空：切换备用罐或启动制氧机
- 管道破裂：关闭破损段，启动备用管路
- 曝气盘损坏：局部更换，其他区域加强曝气
