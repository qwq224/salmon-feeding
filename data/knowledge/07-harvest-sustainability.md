# 三文鱼收获加工与可持续发展

## 第一章：收获前管理

### 1.1 出鱼前准备

**停食 (Starvation/Depuration)**:
- 目的: 排空肠道内容物 → 减少运输中氨氮排放 + 改善肉质
- 时间: 根据水温调整

| 水温 | 停食天数 | 说明 |
|:---:|:---:|------|
| 2-5℃ | 7-10天 | 代谢慢，需更长停食 |
| 5-10℃ | 5-7天 | 标准冬季停食 |
| 10-15℃ | 3-5天 | 最佳投喂期后停食 |
| 15-20℃ | 2-3天 | 代谢快，短期停食即可 |

**品质优化**:
- 虾青素添加: 收获前4-8周, 40-60 mg/kg饲料 → 肉色达 SalmoFan 26-30
- 脂肪控制: 上市前1个月调整饲料脂肪含量 (避免过多腹部脂肪)
- 应激控制: 收获前1周避免任何惊扰 (减少乳酸积累)

### 1.2 出鱼规格与市场匹配

| 规格 (kg) | 目标市场 | 价格溢价 | 养殖周期 |
|----------|---------|--------|---------|
| 1.5-2.0 | 鲜活/小型餐饮 | 基准 | 12-14个月 |
| 2.0-3.0 | 商超冰鲜 | +5-10% | 14-16个月 |
| 3.0-4.0 | 出口冰鲜 (日韩) | +15-20% | 16-18个月 |
| 4.0-5.0 | 高端餐饮/日料 | +20-30% | 18-20个月 |
| >5.0 | 加工 (烟熏/刺身) | +10-15% | 20-24个月 |

### 1.3 收获前质量检测

**必检项目**:
- 体表: 无外伤、无畸形、鳞片完整
- 鳃: 鲜红色、无寄生虫
- 肉色: SalmoFan 色卡评级 (目标≥26)
- 脂肪含量: 背部肌肉 12-18% (近红外NIR快速检测)
- 药物残留: 休药期已过的书面确认

**抽检比例**: 每批 (约5-10吨) 随机抽样10尾进行感官和理化检测

## 第二章：收获与初加工

### 2.1 活鱼运输

**运输前处理**:
1. 停食 (排空肠道)
2. 降温: 2-3℃/h逐渐降至6-8℃ (代谢降低40-60%)
3. 盐浴: 0.3-0.5% NaCl, 1-2小时 (减少渗透应激)
4. 分级: 同箱规格差异<10% (避免大小互残)

**运输参数**:
| 参数 | 最佳范围 | 说明 |
|------|---------|------|
| 水温 | 6-8℃ | 运输中代谢最低 |
| 溶氧 | >8 mg/L | 纯氧增氧 |
| 密度 | 0.3-0.5 kg/L | 鱼:水比例 |
| pH | 7.0-7.5 | 缓冲剂维持 |
| CO₂ | <20 mg/L | 脱气或换水 |
| 氨氮 | <0.5 mg/L TAN | 可加沸石粉吸附 |
| 运输时间 | <12h | 超过需中途换水 |

**运输方式**:
- 活鱼车: 带液氧罐和循环过滤系统的专用运输车
- 活鱼船: 海水网箱→加工厂，保持海水流通
- 航空: 保温箱+氧气袋 (高价值/长途)

### 2.2 宰杀工艺

**人道宰杀 (欧美强制标准)**:

**方法一: 打击致晕 + 放血** (最常用)
- 机械击打: 气压棒打击头部 (瞬时致晕)
- 立即切鳃放血: 切断鳃弓上的主要血管
- 放血时间: 2-3分钟 (12-15℃海水中)

**方法二: CO₂麻醉 + 放血**
- CO₂饱和水: pH降至5.5-6.0
- 麻醉时间: 2-4分钟
- 缺点: 鱼有明显应激反应 (逐渐被淘汰)

**方法三: 电击致晕 + 放血**
- 电压: 110-220V
- 电流: 0.5-1.0A
- 时间: 1-3秒
- 优点: 瞬时致晕，应激最小

**宰后处理**:
- 放血完全性: 检查鳃和肌肉颜色 (优质放血 → 肉色洁白)
- 冰水浸泡: 0-2℃, 30-60分钟 (降温到<4℃)
- 去内脏: 机械或人工，注意不刺破胆囊
- 清洗: 冰水冲洗腹腔
- 分级: 按重量和外观分级

### 2.3 冰鲜与冷冻加工

**冰鲜 (Fresh)**:
- 温度: 0-4℃ (碎冰包裹)
- 保质期: 宰后12-16天 (取决于初始品质)
- 包装: EPS泡沫箱 + 碎冰 + 吸水垫 + 外纸箱
- 运输: 冷链 (<4℃), 空运为主

**冷冻 (Frozen)**:
- 速冻: -40℃ 快速冻结 (1-3小时)
- 贮藏: -20℃至-25℃
- 保质期: 12-18个月
- 方式: 整鱼/去内脏/鱼片 (Fillet)

**超低温 (Sashimi Grade)**:
- 温度: -60℃至-65℃ (超低温冷柜)
- 目的: 杀死寄生虫 (异尖线虫)
- 时间: -60℃ × 24h 或 -35℃ × 15h
- 解冻: 0-4℃ 缓慢解冻 (24-48小时)

## 第三章：可持续发展

### 3.1 环境影响与碳足迹

**三文鱼养殖碳足迹 (kg CO₂e / kg 活鱼)**:

| 排放源 | 网箱养殖 | 陆基RAS | 说明 |
|--------|:---:|:---:|------|
| 饲料生产 | 3.5 | 3.5 | 最大排放源 (鱼粉+鱼油+农作物) |
| 直接能耗 | 0.5 | 3.0 | RAS电力消耗显著 |
| 运输 | 0.8 | 0.5 | 网箱通常更偏远 |
| 包装 | 0.3 | 0.3 | 类似 |
| **合计** | **5.1** | **7.3** | 全球平均约6.0 |

对比: 牛肉 27-60, 猪肉 7-12, 鸡肉 3-6

### 3.2 认证体系

**ASC (Aquaculture Stewardship Council) — 最权威认证**:
- 负责任饲料: 鱼粉鱼油来自MSC认证渔业
- 水质管理: 监测DO/TAN/TSS等, 符合当地排放标准
- 鱼类福利: 密度限制、人道宰杀、健康管理
- 社会责任: 工人权益、社区关系

**BAP (Best Aquaculture Practices) — GSA认证**:
- 加工厂: HACCP + 食品安全
- 养殖场: 环境责任 + 动物福利
- 孵化场: 生物安全 + 可追溯
- 饲料厂: 原料来源 + 质量安全

**GlobalG.A.P.**:
- 综合农场保证 (IFA): 食品安全 + 环境 + 工人福利
- 水产养殖模块: 专门针对水产养殖

**有机认证**:
- EU Organic: 禁止使用合成抗氧化剂，限制养殖密度
- USDA Organic: 目前不认证水产 (正在制定标准)
- 中国有机产品: 允许认证水产养殖

### 3.3 循环经济与副产物利用

**加工副产物占比** (占活鱼重):
- 头: 10-12%
- 内脏: 8-10%
- 脊骨/鳍: 8-10%
- 皮: 3-5%
- 可食用肉: 60-65%

**副产物高值化利用**:
- 鱼油: 从边角料提取Omega-3 (EPA/DHA), 高价值保健品
- 鱼粉: 头/骨/内脏 → 鱼粉 (水产饲料)
- 胶原蛋白: 鱼皮提取, 化妆品/食品添加剂
- 鱼精蛋白: 鱼白 (精巢), 抗菌肽, 保健品
- 酶解产物: 蛋白酶水解 → 功能性多肽
- 羟基磷灰石: 鱼骨煅烧 → 骨修复材料

### 3.4 未来趋势

**精准养殖 (Precision Aquaculture)**:
- AI视觉: 自动识别个体大小、摄食行为、健康状态
- IoT传感器: DO/温度/氨氮/水流 全时在线监测
- 数字孪生: 虚拟鱼群模拟 → 优化投喂和管理决策
- 区块链溯源: 从孵化到餐桌的全程可追溯

**新型养殖系统**:
- 深远海养殖 (Offshore): 离岸20-50km, 水深>50m
- 闭合式网箱 (Semi-closed): 减少与环境交互
- 多营养层级综合养殖 (IMTA): 鱼-贝-藻共生
- 陆海接力: 陆基育苗+海水养成

**替代蛋白饲料**:
- 昆虫蛋白: 黑水虻工业化生产 (年产能已达万吨级)
- 单细胞蛋白: 天然气发酵 → 细菌蛋白 (FeedKind)
- 微藻: 光合/异养培养 → DHA/EPA直接来源
