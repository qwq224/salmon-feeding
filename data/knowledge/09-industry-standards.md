# 三文鱼养殖行业标准与法规汇编

## 第一章：中国标准体系

### 1.1 国家标准 (GB)

**GB 11607-89 渔业水质标准**
这是中国水产养殖的基本水质标准，规定了养殖水体的各项指标限量。对于冷水性鱼类（含三文鱼/虹鳟）：

| 参数 | 标准值 | 备注 |
|------|--------|------|
| 溶解氧 | ≥6 mg/L (连续24h中16h以上) | 冰封期≥4 mg/L |
| pH | 6.5-8.5 | 淡水 |
| 生化需氧量 (BOD₅) | ≤5 mg/L | 冰封期≤3 mg/L |
| 总大肠菌群 | ≤5000个/L | |
| 汞 | ≤0.0005 mg/L | |
| 镉 | ≤0.005 mg/L | |
| 铅 | ≤0.05 mg/L | |
| 铬 (六价) | ≤0.1 mg/L | |
| 铜 | ≤0.01 mg/L | |
| 锌 | ≤0.1 mg/L | |
| 镍 | ≤0.05 mg/L | |
| 砷 | ≤0.05 mg/L | |

### 1.2 农业行业标准 (NY)

**NY 5072-2002 无公害食品 渔用配合饲料安全限量**
规定了渔用饲料中有害物质的允许量：
- 黄曲霉毒素 B₁: ≤10 μg/kg (鱼苗饲料) / ≤20 μg/kg (成鱼饲料)
- 总砷: ≤3 mg/kg
- 铅: ≤5 mg/kg
- 汞: ≤0.5 mg/kg
- 镉: ≤3 mg/kg (鱼虾饲料)
- 铬: ≤10 mg/kg
- 氟: ≤350 mg/kg
- 游离棉酚: ≤300 mg/kg
- 异硫氰酸酯: ≤500 mg/kg
- 噁唑烷硫酮: ≤500 mg/kg
- 氰化物: ≤50 mg/kg
- 亚硝酸盐: ≤15 mg/kg (以亚硝酸钠计)
- 六六六: ≤0.3 mg/kg
- 滴滴涕: ≤0.2 mg/kg

**NY 5071-2002 无公害食品 渔用药物使用准则**
关键条款:
- 严禁使用: 孔雀石绿、硝基呋喃类、氯霉素、己烯雌酚、喹乙醇
- 允许使用但需遵守休药期: 土霉素(≥21天)、氟苯尼考(≥14天)、磺胺类(≥30天)
- 提倡使用: 中草药制剂、微生态制剂、免疫增强剂

**NY/T 755-2003 绿色食品 渔药使用准则**
在NY 5071基础上增加了绿色食品的特殊要求:
- 优先使用: 生物制剂(疫苗、益生菌)、物理方法
- 治疗用药: 须有明确诊断，并经执业兽医处方
- 禁止预防性使用抗生素
- 记录要求: 药名、剂量、给药途径、起止时间、休药期、处方兽医

### 1.3 水产行业标准 (SC)

**SC/T 7015-2011 冷水性鱼类养殖技术规范**
涵盖冷水性鱼类 (包括鲑鳟) 的养殖全过程技术要求:
- 养殖场选址: 水源充足、水质符合GB 11607、交通便利
- 池塘/池槽: 流水≥1.0 m/s, 水深≥1.2m
- 苗种质量: 规格整齐(CV<15%), 无病无伤, 检疫合格
- 养殖密度: 稚鱼1000-3000尾/m² → 幼鱼200-500尾/m² → 成鱼15-30 kg/m³(RAS)
- 饲料: 符合NY 5072, 蛋白≥42%(稚鱼)/≥38%(成鱼)
- 日常管理: 每日巡塘≥2次, 记录水温/DO/投喂量/死鱼数

### 1.4 地方标准 (DB)

**DB63/T 1042-2011 青海省 虹鳟网箱养殖技术规范**
- 养殖水域: 水库/湖泊, 水深>15m, 透明度>3m, DO>6mg/L
- 网箱规格: 5×5m 或 6×6m, 深4-6m
- 放养密度: 100-250g鱼种 100-150尾/m³
- 投喂率 (100-250g): 4℃ 0.5%, 10℃ 1.1%, 16℃ 1.6-1.8%, 20℃ 2.0%
- 投喂频率: 水温<10℃ 1-2次/d, 10-20℃ 2-3次/d
- 出塘规格: 冰鲜出口3-5kg, 鲜活1.5-3kg

**DB63/T 2430-2025 青海省 虹鳟人工繁殖技术规范** (新版)
- 亲鱼选择: 雌鱼≥2kg/3龄, 雄鱼≥1kg/2龄
- 催产水温: 8-12℃
- 孵化积温: 320-400度日
- 稚鱼开口: 250-300度日

## 第二章：国际标准体系

### 2.1 FAO 标准与指南

**FAO Code of Conduct for Responsible Fisheries (CCRF, 1995)**
负责任渔业行为守则，水产养殖相关条款:
- 第9条: 水产养殖发展 — 要求环境影响评估、合理选址、防止病害传播
- 第10条: 渔业管理纳入沿海区域管理
- 第11条: 收获后处理与贸易 — HACCP食品安全管理

**FAO Technical Guidelines for Responsible Fisheries — Aquaculture Development**
详细的技术指南:
- 养殖场选址与环境管理
- 外来种/转基因种使用规范
- 病害管理与渔药使用
- 饲料管理与可持续原料
- 水质管理与排放标准

### 2.2 OIE (WOAH) 水生动物卫生标准

世界动物卫生组织 (OIE/WOAH) 水产法典:

**法定报告疫病** (鲑科相关):
- 传染性鲑鱼贫血症 (ISA, Infection with HPR-deleted ISAV)
- 病毒性出血性败血症 (VHS)
- 传染性造血器官坏死症 (IHN)
- 鲑鱼甲病毒感染 (SAV/PD)
- 鲑鱼立克次体病

**贸易建议**:
- 活鱼运输: 原产地证书 + 健康证明
- 鱼卵: 需经有机碘消毒处理
- 加工产品: 需HACCP认证

### 2.3 认证标准

**ASC Salmon Standard (v1.4, 2023)**:
水产养殖管理委员会三文鱼标准，7项原则:
1. 遵守法律法规
2. 保护自然生态系统和生物多样性
3. 保护水资源
4. 负责任使用资源
5. 鱼类健康与福利管理
6. 社会责任
7. 可追溯性与透明度

关键量化指标:
- 海虱: 雌性成虫<0.5只/鱼 (触发处理阈值0.25)
- 抗生素: 仅限兽医处方，禁止预防性使用
- 鱼粉鱼油: 来自MSC认证或FIP渔业
- 逃逸: 每生产周期<300尾
- 死亡率: 月死亡率需报告，高于基准值需调查

**BAP (Best Aquaculture Practices) — Salmon Farms**:
全球水产联盟 (GSA) 最佳实践认证:
- 加工厂标准: HACCP + 食品安全管理体系
- 养殖场标准: 环境责任 + 动物福利 + 社区关系
- 孵化场标准: 生物安全 + 可追溯
- 饲料厂标准: 原料来源透明 + 质量安全

**GlobalG.A.P. Aquaculture Module**:
- 综合农场保证 (IFA v6)
- 水产养殖检查表: 涵盖食品安全、环境、工人健康安全、动物福利四大模块
- 中国已有多家罗非鱼/对虾养殖场获得GlobalG.A.P.认证
