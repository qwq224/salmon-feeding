# 三文鱼疾病防控与生物安全体系

## 第一章：疾病概论

### 1.1 三文鱼疾病分类

三文鱼养殖中的疾病可分为四大类:

**细菌性疾病**:
- 弧菌病 (Vibriosis): 鳗弧菌、杀鲑弧菌引起
- 疖疮病 (Furunculosis): 杀鲑气单胞菌
- 细菌性肾病 (BKD): 鲑肾杆菌
- 肠炎红嘴病 (ERM): 鲁氏耶尔森菌
- 烂鳍病: 柱状黄杆菌

**病毒性疾病**:
- 传染性胰脏坏死症 (IPN): 双链RNA病毒
- 传染性造血器官坏死症 (IHN): 弹状病毒
- 鲑鱼贫血症 (ISA): 正粘病毒
- 胰腺病 (PD/SAV): α病毒
- 病毒性出血性败血症 (VHS): 弹状病毒

**寄生虫病**:
- 海虱 (Sea Lice): 鲑疮痂鱼虱
- 阿米巴鳃病 (AGD): 副变形虫
- 三代虫病: 三代虫属
- 白点病 (Ich): 多子小瓜虫

**营养与环境性疾病**:
- 脂肪肝综合征: 高能饲料 + 缺乏胆碱
- 白内障: 蛋氨酸缺乏或渗透压应激
- 气泡病: 氮气过饱和
- 脊柱侧弯: 维生素C缺乏

### 1.2 疾病发生三角

疾病 = 病原体 × 易感宿主 × 适宜环境

三个因素缺一不可:
1. **病原体**: 必须有足够数量 (>感染剂量)
2. **易感宿主**: 免疫力低下 (应激、营养不良)
3. **适宜环境**: 水温、水质、密度等利于病原体繁殖

防控策略应同时从三个角出发:
- 减少病原体: 消毒、隔离、生物安保
- 增强宿主: 疫苗、营养、减少应激
- 改善环境: 水质管理、合理密度

## 第二章：重大疾病详解

### 2.1 弧菌病

**病原特征**: 革兰氏阴性，弧形杆菌，嗜盐 (0.5-3% NaCl)

**流行病学**:
- 高发水温: >15℃
- 传播途径: 水体水平传播，经伤口或鳃感染
- 潜伏期: 2-7天 (水温越高越短)
- 死亡率: 急性爆发可达50-80%

**临床症状**:
- 第一阶段 (感染1-3天): 食欲减退，体色变暗
- 第二阶段 (3-5天): 鳍基、肛门出血，眼球突出
- 第三阶段 (5-7天): 全身败血症，腹部膨大，大量死亡

**肉眼病变**:
- 鳃部: 苍白 (严重贫血)
- 肝脏: 肿大、出血点
- 脾脏: 肿大、软化
- 肠道: 卡他性炎，充满黄色粘液
- 体腔: 血性腹水

**治疗**:
- 一线: 土霉素 75-100 mg/kg/d × 7-10天 (休药期21天)
- 二线: 氟苯尼考 10 mg/kg/d × 7天 (休药期14天)
- 三线: 磺胺间甲氧嘧啶 200 mg/kg/d × 5天 (休药期30天)

### 2.2 传染性鲑鱼贫血症 (ISA)

**国际兽疫局(OIE)法定报告疫病**

**病原**: ISA病毒，正粘病毒科，有囊膜，分段负链RNA

**流行病学**:
- 自然宿主: 大西洋鲑 (Salmo salar)
- 携带者: 虹鳟、海鳟 (无症状携带)
- 传播: 水平传播为主 (海水网箱间距离<5km风险极高)
- 潜伏期: 2-4周 (长的可达3个月)
- 死亡率: 累积可达20-100%

**诊断标准** (OIE):
1. 临床症状: 严重贫血 (Hct<10)、腹水、肝脾肿大
2. 病理: 肝细胞坏死、肾间质出血
3. 病原检测: RT-PCR阳性 + 测序确认
4. 病毒分离: SHK-1或ASK细胞系

**防控**:
- 确诊后: 全群扑杀 + 消毒 + 至少3个月休渔
- 挪威: 1990年代ISA大爆发 → 严格分区管理 + 扑杀政策 → 有效控制
- 智利: 2007-2009年ISA危机 → 产业损失超20亿美元 → 全面改革

### 2.3 海虱综合管理 (IPM)

**经济损失**: 全球鲑鱼养殖业年损失超10亿美元 (挪威约5亿)

**种类**:
- 鲑疮痂鱼虱 (L. salmonis): 北半球主要种类
- 加州鱼虱 (C. rogercresseyi): 智利主要种类

**生活史** (10℃, L. salmonis):
- 无节幼体I-II: 浮游，不寄生 (3-4天)
- 桡足幼体: 感染期，寻找宿主 (2-3天)
- 附着幼体I-IV: 固定在鱼体上 (8-12天)
- 前成虫I-II: 可移动，开始摄食 (6-8天)
- 成虫: 雌雄异体，雌虫产卵 (持续20-30天)

**综合防控策略**:

1. **生物防控**:
   - 清洁鱼: 隆头鱼 (Wrasse) 和圆鳍鱼 (Lumpfish)
   - 配比: 每100尾鲑鱼配5-10尾清洁鱼
   - 挪威每年使用清洁鱼超5000万尾

2. **物理防控**:
   - 防虱裙 (Skirt): 阻止上层水体的幼体进入网箱
   - 激光: 水下激光自动识别并杀死海虱
   - 温水浴: 30-34℃, 20-30秒 (成虫和幼体脱落)
   - 淡水浴: 3-4小时 (渗透压致死)

3. **化学防控**:
   - 过氧化氢浴: 1500 mg/L × 20分钟
   - 依马菌素苯甲酸酯 (Slice): 饲料添加
   - 氟甲喹: 注意耐药性问题日益严重

4. **管理防控**:
   - 协调休耕: 区域内所有养殖场同步休耕
   - 单一年级养殖: 减少海虱的持续宿主
   - 监测阈值: 平均>0.5只成虫/鱼即需处理

### 2.4 疫苗策略

**核心疫苗 (所有三文鱼必需)**:
| 疫苗 | 接种时间 | 方法 | 保护期 |
|------|---------|------|--------|
| 弧菌+疖疮+冷水弧菌 三联苗 | 20-30g | 腹腔注射 | 12-18月 |
| IPN 灭活苗 | 5-10g 或 20-30g | 浸泡/注射 | 6-12月 |
| PD (SAV) 灭活苗 | 50-80g | 腹腔注射 | 12月 |
| ISA 灭活苗 (海水养殖) | 50-80g | 腹腔注射 | 12-18月 |

**新疫苗 (部分使用)**:
- 海虱疫苗: 研发中，尚无商业化产品
- AGD疫苗: 澳大利亚正在开发
- 多价疫苗: 一针含6-7种抗原 (减少操作次数)

**免疫接种操作规范**:
1. 停食24-48小时
2. 麻醉: MS-222 60-100 mg/L
3. 水温: 不超过10-12℃
4. 注射量: 0.1 mL/尾 (标准)
5. 针头: 23-25G
6. 速度: 2000-4000尾/h/人 (自动注射机)
7. 复苏: 至少48小时恢复摄食

## 第三章：生物安全体系

### 3.1 养殖场分区管理

**红区 (高风险)**:
- 进场消毒通道: 人员/车辆/物品消毒
- 外来鱼检疫区: 至少隔离30天
- 病死鱼处理区: 焚烧或高温化制

**橙区 (过渡区)**:
- 饲料仓库: 防鼠防虫
- 工具消毒间: 各区间工具不共用
- 更衣室: 一区一服一靴

**绿区 (生产区)**:
- 养殖车间: 严格限制人员进出
- 水处理区: 独立运行，防止交叉
- 实验室: 水质/病原检测

### 3.2 日常生物安全操作

**人员管理**:
- 进入生产区: 洗手 → 换工作服 → 换专用靴 → 脚踏消毒池
- 不同养殖车间之间: 换靴 → 手消毒
- 外来访客: 至少48小时未接触其他水产养殖场

**车辆管理**:
- 饲料车: 消毒后进入
- 运鱼车: 一车一消毒，不混用
- 外来车辆: 不得进入生产区

**物品管理**:
- 渔网/工具: 专区专用，定期消毒
- 饲料: 批次管理，先进先出
- 化学药品: 专人专柜，使用登记

### 3.3 病死鱼处理

**日常检死**: 每日早晚各巡塘一次，及时捞出死鱼

**记录**: 数量、重量、外观症状、可能死因

**处理方式**:
- 焚烧: >850℃, 最彻底
- 高温化制: 133℃, 3bar, 20min
- 酸碱处理: 浓酸/浓碱水解
- 严禁: 随意丢弃、掩埋、作为其他动物饲料

**紧急处理 (大规模死亡)**:
- 立即报告当地渔政
- 采样送检: 至少10尾新鲜病鱼
- 封锁养殖区: 禁止外运
- 按照官方指令处置
